# Contributing to this Project.

1. Go to https://github.com/ebunilo/lesson01
2. Fork the repo (It will create a copy of the repo on your own Github account)
3. Click the green "Code" button and copy the clone URL (from your own repo)
4. On your local machine, Open your IDE, and clone the repo with the command `git clone <paste what you copied from above>`
5. Create a new html file with the format `yourname.html` (for example jacinta.html)
6. Open any of the existing profile in the repo, copy the contents and paste in your own html file. Then change the contents to yours for example replace the names with yours.
7. In the README.md file, add your name as a contributor. (copy the last line, paste it below and change the names to yours)
8. Stage (`git add .`), Commit (`git commit -m "add yourname profile"`), and push (`git push`)
9. Go to your Github account on the browser, open the repo, click `Pull Request`
10. Click `New Pull Request`. (confirm that the base is set to `ebunilo:main`)
11. Click `Create Pull Request`

You are done. I will get the notification and merge your PR. And you will get a notification when it is merged.

To verify, from the web browser open your repo, click `Sync fork`. Then in your local IDE, run the command `git pull`
Your changes will appear on your local machine.
